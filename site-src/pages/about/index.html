About

Abhishek Sengar

Builds Android apps, WebGPU experiences and backend systems on Linux and macOS.
Picks Java, Go or Python to fit the task, tuned for performance and usability, and writes tutorials.

Everything here runs in the browser with nothing to install, and every project comes with notes on the techniques, the numbers and the parts that did not work the first time.

What is on the site

  • City Drive, an endless procedural city you can drive through, rendered with WebGPU and streamed by Web Workers.
  • Developer tools that run privately in your browser: a JSON viewer that searches large files on the GPU, a visual CSS editor and a WebGPU vs WebGL benchmark.
  • WebGPU tutorials, twelve short lessons from a first triangle to shadows and post-processing, with a playground for every example.
  • Articles that take the games and tools apart: procedural generation, streaming, car physics, traffic, shadows and GPU text search.
  • wgpu3d, a small GPL-licensed library made from the City Drive engine, for 3D scenes with cars and characters you can play.

How the site is made

The pages are plain HTML and CSS built by a small script, with JavaScript only where a page needs it. The games and tools use WebGPU directly rather than a large engine, so each one stays small enough to read. Nothing you paste into a tool is uploaded.
