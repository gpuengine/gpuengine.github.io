WebGPU Tutorial

WebGPU is the modern way to use the graphics card from a web page. These 12 short lessons take you from your first triangle to 3D scenes, compute shaders and post-processing.

Start learning WebGPU now » Open the Playground

Learning by examples

Every lesson has examples you can edit and run in your browser with the Playground. Change the code, press Run, and see the result straight away.

Example

A complete WebGPU fragment shader:

@fragment
fn fragmentMain() -> @location(0) vec4f {
  return vec4f(0.49, 0.95, 0.61, 1.0);
}
