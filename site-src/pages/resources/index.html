Where to start

I am new to WebGPU.
Read the introduction lesson, then keep the MDN WebGPU reference open while you work through the tutorial.
I know WebGL.
Chrome's From WebGL to WebGPU maps each concept across, and the WebGPU vs WebGL article shows what changes in practice, with numbers.
A demo does not run on my machine.
Check Can I use for your browser version, open WebGPU Report to see your adapter, and follow Chrome's troubleshooting tips.
I need the exact rule for something.
Search the WebGPU specification for API behaviour and validation, or the WGSL specification for shader types, layout and built-ins.
