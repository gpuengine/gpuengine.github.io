What is WebGPU, and why does it matter?

WebGPU is the modern standard for using the graphics card from a web page. It replaces WebGL and, for the first time, brings general-purpose GPU computing to the web.

Graphics and compute in one API

WebGL could only draw. WebGPU can draw and compute: compute shaders run thousands of small programs in parallel, which makes it useful for simulation, data processing, search, image work and machine learning, not just 3D.

Closer to how modern GPUs work

WebGPU is modelled on Vulkan, Metal and Direct3D 12. Work is recorded up front and submitted in batches, so the CPU spends less time telling the GPU what to do and more frames reach the screen.

Shaders written in WGSL

WebGPU programs are written in WGSL, the WebGPU Shading Language. One shader runs the same on Windows, macOS, Linux, Android and iOS, in every browser that supports WebGPU.

Runs where your users already are

WebGPU ships in recent Chrome, Edge and Safari, and in Firefox on Windows. A link is all it takes: no app store, no download, no plugin.

WebGPU questions

Is WebGPU faster than WebGL?
Usually, for scenes with many objects, because WebGPU lowers the cost of each draw call. The bigger change is compute shaders, which WebGL does not have at all.
What can WebGPU be used for besides games?
Anything that benefits from parallel work: developer tools like our GPU-accelerated JSON search, image and video filters, data visualization, physics simulation and running AI models in the browser.
Does my browser support WebGPU?
Recent versions of Chrome, Edge and Safari support it, as does Firefox on Windows; Can I use lists exact versions. Open City Drive: if it runs, your browser has WebGPU.
Do I need to install anything to use gpuengine?
No. Every game, tool and tutorial on this site runs in the browser tab, and tools like the JSON viewer process your data locally.
