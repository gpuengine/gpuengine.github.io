A JSON viewer that stays fast on large files

This free online JSON viewer and editor checks, formats and explores JSON straight in your browser. Paste JSON into the input on the left, open a .json file, or drop one onto the page. The right side shows the document as a formatted tree you can fold, unfold, search and edit.

What you can do

  • Validate JSON: syntax errors are reported with the exact line and column, and Go to error jumps the cursor there.
  • Format and minify: pretty-print with two-space indentation, or strip all whitespace. Numbers and strings are kept exactly as written, so large integers do not lose precision.
  • Collapse and expand nodes: fold any object or array, or use Expand all and Collapse all. Collapsed nodes show how many keys or items they hold.
  • Search keys and values: find text in keys, values or both, with optional case matching. Matches inside folded nodes are revealed automatically.
  • Edit in place: double-click a key or value in the tree to change it. The input on the left updates to match.
  • Copy any key or value: hover a row (or tap it on a phone) and use Copy key or Copy value. Strings are copied as plain text, and objects and arrays as formatted JSON. The status bar shows the selected node's path, such as $.books[2].title, ready to copy.
  • Long lines wrap: minified JSON pasted as one long line wraps in the input, so you never have to scroll sideways. Turn Wrap off for very large files to keep typing fast.

How it handles large JSON without freezing

Parsing runs in a background Web Worker, so the page keeps responding while a large document is read. Instead of building millions of JavaScript objects, the parser records where each key and value sits in the original text in compact typed arrays. The tree only draws the rows on screen, so scrolling stays smooth with millions of nodes. Files too large to edit as text are kept out of the text box while the tree stays fully usable.

Where WebGPU comes in

Search runs on your graphics card. The document is copied to GPU memory once, and a WebGPU compute shader checks every position in the text in parallel, so search time barely grows with file size. Search needs a browser with WebGPU: recent Chrome, Edge or Safari, or Firefox on Windows. Viewing, formatting and editing work in any modern browser.

Questions

Is my JSON uploaded anywhere?
No. Everything runs locally in your browser. Nothing you paste or open is sent to a server.
How large a file can it open?
Files of hundreds of megabytes work on a typical laptop. The limit is your device's memory, and for search, how much GPU memory the browser allows.
Why is search unavailable?
Search runs on WebGPU. If your browser or device does not support it, the search box says so; everything else still works.
Does formatting change my numbers?
No. The formatter copies numbers and strings exactly as they appear in your input instead of converting them through JavaScript numbers.
